# 黄冈通关考　答对就出发！

黄冈文旅引流答题活动——手机端演示网页（纯静态，无需后端）。

## 打开方式

**推荐（本地 HTTP）：**

```bash
cd /workspace/huanggang-tongguan-quiz
python3 -m http.server 8765
```

手机与电脑同一局域网时，浏览器访问：`http://<本机IP>:8765/`  
本机预览：`http://127.0.0.1:8765/`

**也可直接打开文件：**

用手机浏览器打开 `index.html`（部分浏览器 `file://` 下剪贴板 API 可能受限，复制按钮会回退到 `execCommand`）。

## 功能一览

| 功能 | 说明 |
|------|------|
| 热身题 | 固定 1 题（武汉高铁约多久到黄冈） |
| 十关随机 | 每关 3 备题中随机抽 1 道，共 10 关 |
| 即时解析 | 选答后高亮对错并展示简短解析 |
| 兑礼梯度 | ≥7→1 份；≥9→2 份；全对→3 份；不足 7 无礼品 |
| 一次资格 | `localStorage` 锁定；提供「演示重置」 |
| 通关凭证 | 唯一码 + 得分 + 兑礼档 + 时间 + 手机号 |
| 话题复制 | `#黄冈通关考答对就出发#大美黄冈此心安处` |
| 现场领取提示 | 不邮寄；核验凭证 / 转发 / 手机号 |
| 额度提示 | 总额一万、每日约千份（信息提示，非库存系统） |

## 随机抽题逻辑

每次点击「开始答题」时调用 `buildDeck()`：

1. 热身题固定入列；
2. 十个关卡各自的 `bank`（3 题）用 `Math.random()` 抽 1 题；
3. 组成 11 题 `deck`，顺序固定：热身 → 东坡关 → … → 黄梅关。

同一设备再次答题前须点「演示重置」清除记录（正式环境应接账号/短信核验，本页仅为前端演示）。

## 限制说明

- 无后端、无短信、无真实库存扣减；凭证码为前端随机生成。
- 「一设备一次」仅靠浏览器 `localStorage`，清缓存或换浏览器可再次作答。
- 题库与规则来自活动执行方案文档，未编造额外景点事实。
- 正式上线需对接：账号体系、题库服务端下发、核销系统、礼品额度。
